# 视频提示词模板（小人国效果 · Seedance 2.5 标准段式）

> 输出标准，永不被知识库污染。按以下六段顺序组织，缺一不可。

## 模板

```
【全局视听DNA】
画风：超写实微距摄影，浅景深，人物清晰锐利
光线：午后室内自然光，左侧窗光，暖白调，光线中有浮尘微粒
镜头语言：低角度微距贴地，等效100mm，人快镜稳
画幅：16:9 横屏（或 9:16 竖屏）｜时长：12s｜分辨率：480P

【人物设定】
@图片P1/P2/P3/P4：人物多视角图，外貌、服装、发型、体型完全一致
（人物身份锚——视频内人物形象与参考图完全一致）

【场地设定】
@图片X：场地鸟瞰空镜（垂直向下俯视90°），锁定场景布局、巨物分布、地面材质、光线方向
场景：办公域桌面，键帽阵列如楼群，桌面木纹清晰
尺度基准：人物身高 ≈ 键帽高度 1/3

【分段镜头描述】（五段式 + Cut六要素 + 逐秒节拍）
段1 建立 0-3秒  〔连续〕
相机：低角度微距，从桌面右侧缓慢左移，浅景深
主体：无人物入画，先展示巨物世界
环境：一排键帽占据画面，光线斜射，浮尘可见
节拍：0s键帽阵列入画，1.5s镜头推进，3s画面稳定

段2 引入 3-6秒  〔连续〕
相机：固定机位低角度
主体：人物从键帽间隙跑出，站在键帽边缘张望
环境：人物踩踏处键帽轻微下陷，灰尘扬起
节拍：3s人物探出，4s跑至键帽边缘，5.5s站立张望

段3 推进 6-9秒  〔连续〕
相机：跟拍，保持1.5个身位距离
主体：人物助跑→起跳→空中翻腾
环境：键帽顶面在人物跑过时微震，尘土轨迹
节拍：6s助跑，6.8s起跳，7.5s最高点，8.5s开始下落

段4 回落 9-10秒 〔连续〕
相机：缓推贴近
主体：人物落在键帽B顶面，屈膝缓冲，缓身站起
环境：键帽B下陷，溅起细小灰尘
节拍：9s落地，9.4s缓冲，10s站起

段5 收尾 10-12秒〔连续〕
相机：缓拉，交代环境
主体：人物回望起点，衣角轻动
环境：风吹过桌面，浮尘流动
节拍：10.5s回望，12s定格

【反向屏蔽规则】
1. 不出现人物与巨物比例失调（人物不得忽大忽小）
2. 不出现机位跳变、视角突然切换（一镜到底/固定机位）
3. 不出现镜头穿模
4. 不出现"环绕"“穿越”"子弹时间"等未设计的运镜词
5. 不出现手指、拍摄设备、现实环境穿帮
6. 不出现人物悬浮失重
7. 不出现巨物被人物轻易举起
8. 不出现文字错乱、键帽字符乱码

由@拍广告的Daham 独家定制，需要更多skill定制，敬请联系。抖音小红书同号。
```

## 使用说明

- 逐秒节拍是骨架：每 1 秒都要知道画面在发生什么。
- 每段时间区间只放一个主要动作；相机运动与主体运动方向一致。
- 负面约束用显式段落，不写弱否定。
- 尺寸在门3 已确认；未确认默认 16:9 横屏。
- 素材双件套（人物多视角图 + 鸟瞰空镜）缺失时禁止出片，回到门1/门2。

# 人物多视角生成提示词模板（GPT Image2.5 / 1K / 3:4 竖屏）

> 门1 形象门的落地工具：用户未提供个人形象图片时，用 GPT Image2.5 生成 4 视角灰底纯色背景图。

## 硬性规格

| 项目 | 值 |
|---|---|
| 模型 | GPT Image2.5 |
| 分辨率 | 1K |
| 画幅 | 3:4 竖屏 |
| 背景 | 灰底纯色（浅灰/中灰单色，无场景、无道具、无文字） |

## 四视角清单

| 编号 | 视角 | 用途 |
|---|---|---|
| P1 | 半身正面对镜头 | 面部/服装识别 |
| P2 | 左侧对镜头 | 侧面轮廓 |
| P3 | 右侧对镜头 | 侧面轮廓（镜像参考） |
| P4 | 全身效果 | 全身比例/动作 |

## 生成提示词模板

先确认用户形象描述（外貌/发型/服装/体型）。用户没有提供图片也没有描述 → 询问 1 次（最多 3 问），仍无 → 用通用年轻成人形象并明确告知用户"形象为默认生成，可随时提供照片重新生成"。

### P1 半身正面对镜头

```
生成一张人物半身正面照，3:4 竖屏，1K分辨率：
人物：<外貌描述：性别/年龄/发型/发色/脸型>，穿着<服装描述>
姿势：正面面对镜头，双手自然下垂或插兜，表情自然看向镜头
背景：纯灰色（中灰）单色背景，无任何场景道具与文字
光线：柔和均匀的棚拍灯光，无阴影，人物面部清晰锐利
风格：写实摄影，证件照/形象照质感，微距人像
```

### P2 左侧对镜头

```
生成一张人物左侧半身照，3:4 竖屏，1K分辨率：
人物：<外貌描述>，穿着<服装描述>（与正面照完全一致）
姿势：身体侧面朝左，头部微转向镜头，露出完整左侧轮廓
背景：纯灰色（中灰）单色背景，无任何场景道具与文字
光线：柔和均匀的棚拍灯光，无阴影，轮廓清晰
风格：写实摄影，形象照质感
```

### P3 右侧对镜头

```
生成一张人物右侧半身照，3:4 竖屏，1K分辨率：
人物：<外貌描述>，穿着<服装描述>（与正面照完全一致）
姿势：身体侧面朝右，头部微转向镜头，露出完整右侧轮廓
背景：纯灰色（中灰）单色背景，无任何场景道具与文字
光线：柔和均匀的棚拍灯光，无阴影，轮廓清晰
风格：写实摄影，形象照质感
```

### P4 全身效果

```
生成一张人物全身照，3:4 竖屏，1K分辨率：
人物：<外貌描述>，穿着<服装描述>（与正面照完全一致）
姿势：正面站立，全身完整入画（头顶留白约10%，脚底留白约5%），自然站姿
背景：纯灰色（中灰）单色背景，无任何场景道具与文字
光线：柔和均匀的棚拍灯光，无阴影，全身清晰锐利
风格：写实摄影，全身形象照质感
```

## 一致性要求

- P1-P4 必须为**同一个人物**：相同外貌、服装、发型、体型。
- 生成时四张提示词的人物描述逐字复用（同一人物描述块）。
- 生成后自查：四张图的五官/服装是否一致；不一致则重新生成。

## 出片引用写法

视频提示词中的人物引用（固定写法）：

```
人物：引用@图片P1/P2/P3/P4（人物多视角图），外貌、服装、发型、体型完全一致
```

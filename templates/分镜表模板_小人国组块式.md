# 模板 · 小人国组块式分镜表

> 用途：门5（分镜门）的标准产出物。向下可直接转成 Seedance 2.5 视频提示词（六栏目）。
> 字段规范：核心字段不可删不可改名，扩展字段用小写下划线命名，`shot_id` 为全局唯一关联键。

## 一、全片头部（一次填写）

```
【项目】小人国电影感出片
【文案】原文粘贴
【尺寸】16:9 横屏 / 9:16 竖屏（未指定默认 16:9）
【总时长】12s（单段 ≤30s）
【风格方案】A 超写实 / B 超现实魔幻 / C 荒诞无厘头 / D 高速穿越
【人物锚】@图片P1-P4（3:4 灰底四视角）
【空间锚】@图片X（垂直向下俯视 90° 鸟瞰空镜）
【尺度基准】人物身高 ≈ 键帽高度的 1/3（全片统一，写死）
【光影基调】午后室内自然光，左侧窗户射入，暖白调，光线中有浮尘微粒
【单元数/组数】N 单元 → M 组（M0.5 依据：___）
【结构结论】强锚定位置：G_-镜_ ｜ 全片微距数：_ ｜ 硬切次数：_
```

## 二、组头（每组一块）

```
G1 · 组类型：建立组 · 锚定句："早上九点，我的桌面就是整个宇宙"
叙事功能：起因 · 情绪走向：平静 → 好奇
镜数：2 镜（2 单元 · 建议 1-3 · 校验合格）
组间衔接：视线接力 → G2 ｜ 连续性锚点：午后窗口光、键盘阵列
本组视觉事件：上帝视角垂直俯拍（与鸟瞰空镜同机位）
尺度锚定层级：弱 → 中 ｜ 强锚定位置：—
```

|---|---|---|---|---|---|---|---|---|---|---|---|---|
| G1-S1 | 0-3s | L2 远景 | 正前 0°/ 高机位 +1 / 24mm | 高空缓推下降 | 〔连续〕〔稳〕 | 垂直俯拍桌面全貌，键盘方阵如街区，一只杯子立在右侧如高楼；画面下方有个米粒大的影子在移动 | 桌面浮尘在光柱里缓慢飘 | 杯口热气缓慢上升 | 明暗（窗光柱对准影子）+ 距离（空旷处独行） | — | 3s | 环境底噪、远处键盘轻响 |

**字段说明**

| 字段 | 必填 | 说明 |
|---|---|---|
| shot_id | ✓ | `G1-S1` 格式，全局唯一 |
| duration_sec | ✓ | 单镜 1.2–6s，理想 1.5–4s |
| shot_size | ✓ | L1–L7 + 中文名 |
| camera_angle | ✓ | 方位 8 档 + 高度 5 档 + 焦段 |
| camera_move | ✓ | 缓推/缓拉/横移/跟拍/垂直升降/固定 |
| transition | ✓ | 〔连续〕〔硬切〕 + 节奏〔快〕〔慢〕〔顿〕〔抖〕〔稳〕 |
| visual_desc | ✓ | 白描，只写可见可拍，人物动作写完整因果链 |
| physical_detail | ✓ | ≥2 项，接触 + 重力/惯性保底 |
| giant_reaction | ✓ | 巨物必须有反应，不许当死背景 |
| subject_isolation | ✓ | 颜色/距离/明暗/构图 至少两项 |
| macro_point | 每组必有一处 | 微距爆点内容（字符/像素/纹理/汗毛） |
| anchor_level | 组头必填 | 强/中/弱锚定 |
| light_hard | 选填 | 硬光/柔光 + 冷暖 + 方向 |
| focal_mm | 选填 | 与 camera_angle 内焦段一致 |
| visual_event | 选填 | 本镜承担的视觉事件 |

## 四、下游字段映射（转视频提示词用）

| 分镜表字段 | 六栏目落位 |
|---|---|
| shot_id + duration_sec | `【时间轴】` 的连续区间（0-3秒 / 3-6秒） |
| visual_desc + physical_detail + giant_reaction | `【时间轴】` 的白描正文 |
| shot_size + camera_angle + camera_move | 白描里的机位句（含方位/高度/焦段/运动） |
| anchor_level + 尺度基准 | `【连续性】`（比例一致性声明） |
| 人物锚 + 空间锚 | `【参考】`（@图片P1-P4 / @图片X） |
| 台词/音效 | `【旁白和声音】` |
| 所有"不出现…"约束 | `【反向提示词】` |
| 全片风格 + 光影基调 | `【Generation Unit】` |

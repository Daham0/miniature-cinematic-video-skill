# 场地鸟瞰空镜提示词模板（GPT Image2.5 / 1K）

> 门2 场地门的落地工具：生成场地空镜，必须为**鸟瞰视角（垂直向下俯视 90°）**，提示词显式体现该机位。

## 硬性规格

| 项目 | 值 |
|---|---|
| 模型 | GPT Image2.5 |
| 分辨率 | 1K |
| 画幅 | 16:9 横屏 或 9:16 竖屏（与出片尺寸一致） |
| 机位 | **垂直向下俯视 90°（鸟瞰空镜 / top-down view）** |

## 生成提示词模板

### 用户提供场地描述时

```
生成一张场地鸟瞰空镜图片，16:9 横屏（或 9:16 竖屏），1K分辨率：
机位：垂直向下俯视90°的鸟瞰空镜（top-down view），相机正对地面/桌面，无透视倾斜
场景：<场景域与描述，如"办公桌面，键盘占据画面中部，键帽阵列整齐排列">
巨物清单：<列出可放大的物体及分布，如"键盘左侧放着一只白色马克杯，右侧散落几块曲奇饼干">
地面材质：<材质描述，如"深色木纹桌面，纹理清晰可见，键帽字符可辨">
光线：<光线方向，如"光线从画面上方射入，左亮右暗">
尺度提示：画面内无人物；预留空旷区域供人物表演；巨物与空旷区域比例约 7:3
风格：超写实摄影，锐利清晰，无文字水印
```

### 用户提供场地参考图时

```
参考 @图片X（用户场地图）的空间布局，生成一张同场景的鸟瞰空镜：
机位：垂直向下俯视90°的鸟瞰空镜（top-down view）
场景：与参考图相同场地，重新按鸟瞰角度构图
巨物清单：<从参考图提取，如"参考图中间的咖啡杯移到画面右上角，左侧书本摊开">
地面材质：<按参考图材质>
光线：<按参考图光线方向，鸟瞰视角下调整>
尺度提示：画面内无人物；预留空旷区域供人物表演
风格：超写实摄影，锐利清晰，无文字水印
```

## 空镜内容检查表

- [ ] 机位为垂直向下俯视 90°（提示词显式写出）
- [ ] 含巨物清单与分布
- [ ] 含地面材质
- [ ] 含光线方向
- [ ] 画面内无人物（空镜）
- [ ] 预留空旷表演区
- [ ] 无文字/水印/乱码

## 出片引用写法

视频提示词中的场地引用（固定写法）：

```
场地：引用@图片X（鸟瞰空镜），锁定场景布局、巨物分布、地面材质、光线方向
```

# 03 · Cut规则与节奏编排

> 小人国视频的"电影感"来自镜头拆解与节奏控制。**先排节奏，再填画面。**

## 1. Cut 六要素（每个镜头必须写全）

| 要素 | 说明 | 示例 |
|---|---|---|
| 时长 | 该镜头时间区间 | `0-3秒` |
| 景别 | 远景/全景/中景/近景/特写/大特写 | 微距特写 |
| 机位 | 相机位置与高度 | 低角度贴桌面 |
| 运动 | 相机动（推/拉/移/摇/跟/固定） | 从右侧缓慢左移 |
| 主体 | 人物动作链 | 助跑→起跳→腾空 |
| 环境 | 巨物反应 + 环境细节 | 键帽轻微下陷 |

## 2. 接法标签

每个镜头之间必须标注接法：

- **〔连续〕**：同一镜头内的连续运动（一镜到底、跟拍、缓推），时间区间连续（`0-3秒`、`3-6秒`）。
- **〔硬切〕**：瞬间切换机位/景别（适合快节奏、卡点、情绪冲击），Seedance 2.5 用不同时间区间表达。

> Seedance 2.5 使用**连续时间区间**（0-3秒、3-6秒、6-9秒），不使用 Shot N 编号。一镜到底＝一个连续时间区间全程不断点；硬切＝下一时间区间直接切新机位。

## 3. 局部节奏标签

在 Cut 描述里附加节奏标签，控制段内张力：

```
〔快〕：主体动作快速、镜头跟随紧凑
〔慢〕：慢动作、缓推、留白
〔顿〕：动作停顿、蓄力、静帧感（常用于起跳前/碰撞前）
〔抖〕：手持晃动、冲击感（碰撞瞬间）
〔稳〕：稳定构图、观察感（建立段落）
```

节奏标签不改变镜头时长，只改变段内运动速度感。

## 4. 逐秒节拍（Per-Second Beat）

**每 1 秒都要知道画面在发生什么。** 输出分镜时，把关键时间点写成节拍表：

```
0.0s  建立：桌面微距，巨物键帽阵列入画
1.5s  人物从键帽间隙探出（尺度锚定）
2.5s  人物跑到键帽边缘（环境动：踩得键帽微动）
4.0s  蓄力（顿）——助跑
4.5s  起跳腾空（快）
6.0s  空中翻腾至最高点
7.0s  下落（重力弧线）
8.0s  落在另一枚键帽上，键帽下陷、溅尘（环境动）
9.5s  人物缓身站起
11.0s 回望起点，风吹衣角
12.0s 定格
```

**节拍表是提示词的骨架**：写提示词时逐秒填充三动（相机动/主体动/环境动）。

## 5. 子弹时间与时间重映射（慢动作设计）

小人国效果中常用"正常速度 + 子弹时间"混合节奏。设计要点：

- **子弹时间的本质是时间重映射**：真实时间轴不变，动画时间轴局部减速（如速度 1→0.15），恢复后继续。
- **进入/退出要平滑**：不要瞬间变速，给 0.5-0.7s 过渡（速度 1→0.15→1）。
- **子弹时间里主体和环境都要慢**：人物悬空旋转、巨物悬空倒下、尘埃缓慢浮动，三者共享慢速，才成立。
- **子弹时间与撞击同步**（推荐）：撞击瞬间进入子弹时间，人物被甩出、巨物被撞倒，一起慢动作，戏剧性最强。

### 一镜到底 + 子弹时间的提示词写法

```
相机：一镜到底，固定机位/沿曲线连续运动，无剪辑、无视角跳变
时间：0-3秒正常速度，3-6秒进入子弹时间（慢动作0.15倍），6-12秒恢复正常
主体：人物撞杯被甩起，悬空缓慢旋转360°
环境：杯子被撞倒，在子弹时间内缓慢倾斜，随后倒完
负面：不出现切镜、不出现视角跳变、不出现环绕
```

> 白模预演对子弹时间至关重要：先写 `timeWarp(t)` 时间重映射函数（见 `06_白模运镜预演.md`），验证 τ 时间轴与真实时间轴对齐后再写提示词。

## 6. 文案 → Cut 自动拆分规则

当用户只给文案/旁白时，按规则自动拆成 Cut：

1. **一句话 = 一个语义单元**。按句号/逗号/情绪转折拆分。
2. **情绪动词分配镜头**：动作词（跑、跳、撞、推）→ 动态镜头；状态词（站、望、停）→ 静态/缓推镜头。
3. **每 2-4 秒一个 Cut**（短句快切可 1-2 秒）。
4. **文案的关键名词 = 视觉主体**：名词"杯子"→ 环境巨物 + 人物与之互动；名词"键盘"→ 场景基调。
5. **情绪高潮词（终于、突然、竟然）→ 安排硬切或子弹时间**。
6. **拆分后按五段式重排**（`01_三动原则与五段式结构.md`）：确保有建立、引入、推进、回落、收尾。

### 示例

文案："小人国里，他骑着摩托冲过键盘，撞倒一杯咖啡，飞了出去。"

```
Cut1 0-3秒  〔连续〕 微距全景，桌面键盘阵列，人物骑摩托入画（建立）
Cut2 3-6秒  〔连续〕 中景跟拍，摩托加速冲过键帽间隙，键帽被气流带得微晃（推进）
Cut3 6-8秒  〔连续〕 近景，撞上咖啡杯（巨物），杯身倾倒、人物被甩出（高潮·撞击）
Cut4 8-10秒 〔连续〕 特写，人物空中翻腾、杯倒下溅出咖啡液滴（回落）
Cut5 10-12秒〔连续〕 中景，人物落地翻滚停在杯旁，抬头回望（收尾）
```

# 09 · 组级策划引擎（M0–M3）

> 来源：分镜策划Skill 决策层，按小人国尺度改造。
> 本层回答"**这组是什么组、几个镜头、什么结构、视觉事件是什么**"。不写完本层，不许进入景别与机位分配（那属于 `10_镜头约束与电影感.md`）。

## 0. 为什么必须先定组

小人国视频最容易翻车的地方不是画面不好看，而是**镜头之间没有因果**：一堆漂亮微距空镜堆在一起，人物忽大忽小，观众不知道自己在看什么故事。

正确顺序（不可逆）：

```
文案 → M0 画面化 → M0.5 镜数决策 → M1 节拍功能 → M2 组类型 → M3 组内结构
                                                              ↓
                                              才允许进入 10（景别/角度/电影感）
```

**反过来的结果就是"技巧拼盘"**：先想好一个炫酷机位，再硬塞进叙事里——这种镜头往往过不了质检。

## 1. M0 文案画面化

### 1.1 可拍词 / 不可拍词拆分

| 类型 | 例子 | 处理 |
|---|---|---|
| **可拍词** | 跑、跳、撞、推、倒、抬头、按下、踩 | 直接转动作，配镜头 |
| **不可拍词** | 效率、专业、高级感、内卷、边界感、电影感、提示词 | 走第 1.2 节五条联想路径 |

### 1.2 五条联想路径（每个不可拍词至少走 3 条）

| 路径 | 做法 | 例：把"效率"变小人国画面 |
|---|---|---|
| **具象化** | 换成能看见的物件 | 巨型秒表、堆成山的文件夹 |
| **动作化** | 换成人物可执行动作 | 人物在键帽间狂奔、连按三下巨型回车键 |
| **环境化** | 用环境状态承载 | 桌面时钟指针扫过的巨大阴影压过人物 |
| **对比化** | 大小/快慢/多少的极端对比 | 一个人推一整摞比自己高的纸 |
| **通感化** | 把听觉触觉变成画面 | 敲击声震起桌面的灰尘波浪 |

每条路径产 1–2 个候选，**一个不可拍词产出 2–4 个画面候选**再筛选。

### 1.3 来源优先级（选候选时按此排序）

1. **文案语境**（文案自己提到的物件/动作）——最高优先
2. **身体随身**（手机、手、鞋、眼镜、咖啡）
3. **场景合理**（该场地真实会出现的巨物：办公桌=键盘/杯/便签；厨房=砧板/豆子/勺）
4. **通用意象**（最后才用，容易俗套）

### 1.4 俗套意象黑名单（命中直接打回换路径）

```
下雨=悲伤 / 时钟=时间 / 飞鸟=自由 / 乱麻=内耗 / 迷宫=困惑 / 悬崖=危机
灯泡=灵感 / 齿轮=运转 / 沙漏=流逝 / 蚂蚁=勤劳 / 玻璃罩=压抑
```

小人国专属注意：**巨人视角踩人、人物被当虫子拍**——除非文案本身讲权力/压迫，否则属负面表达，默认不用。

### 1.5 输出（M0 卡）

```
关键词 → 可拍/不可拍 → 联想路径 → 候选画面(2-4) → 选定锚点 → 来源优先级
```

## 2. M0.5 镜数决策

### 2.1 数语义单元

把文案切成"一个意思"为单位的单元，四类：

- **动作单元**（他冲了过去）
- **信息单元**（新人第一天）
- **变化单元**（杯子倒了）
- **概念单元**（这才叫效率）

**一句台词 = 一个单元 = 一组**（锚定句纪律，不许一句话拆到两个镜头讲）。

### 2.2 时长校验

| 参数 | 值 |
|---|---|
| 口播语速 | **4–5 字/秒** |
| 单镜理想时长 | **1.5–4 秒**（校验窗 1.2–6 秒） |
| 默认总时长 | **12 秒**（Seedance 2.5 单段上限 30s） |
| 时长算法 | 文案字数 ÷ 4.5 ≈ 口播秒数；再按镜头数反推单镜时长 |

例：60 字文案 ≈ 13.3 秒口播，若目标 12s 需提速或砍句；12s ÷ 4 镜 = 3s/镜，合格。

### 2.3 拆组信号（命中任一就拆组）

- 语义单元 **N ≥ 6**
- 总时长 **> 12s**
- 文案里有 **大转折**（但是/突然/结果）
- 情绪**多次位移**（平静→紧张→释然→亢奋）
- 同组内**功能冲突**（举例 + 内省）

### 2.4 输出（M0.5 卡）

```
单元数 N = ? → 功能系数 → 建议镜数区间 [x, y] → 拆组判断 → 组数 M
```

建议镜数区间参考：`3–5 单元 → 1 组 4 镜`；`6–9 单元 → 2 组各 3–4 镜`；`10+ 单元 → 3 组以上`。

## 3. M1 节拍功能（小人国版六 + 一）

对每个锚定句标功能，功能决定组类型：

| 功能 | 判定 | 典型文案 | 镜数倾向 |
|---|---|---|---|
| **建立** | 交代场地、尺度、人物位置 | "早上九点，我的桌面就是整个宇宙" | 1–3 |
| **引入** | 人物进入、尺度锚定首次接触巨物 | "他从键帽缝隙里钻出来" | 1–2 |
| **推进** | 展开动作链、连续空间移动 | "一路冲过杯子、便签、还有半块饼干" | 2–4 |
| **转折** | 情绪或逻辑转向 | "直到他撞上了那杯咖啡" | 1–2 |
| **高潮** | 撞击、腾空、子弹时间、奇观 | （文案里的爆发句） | 1–3 |
| **落点** | 金句、结果、定格、标题文字 | "小人国里，效率是跑出来的" | 1–2 |
| **视觉事件** | 文案没有，但需要一个奇观镜提神 | （无台词，插在两组之间） | 1–3 |

**规则**：一句一功能；混合功能按主导功能标，两功能各 ≥2 单元 → 触发拆组。

## 4. M2 组类型（小人国八组）

| 组类型 | 镜数 | 功能 | 小人国特征 |
|---|---|---|---|
| **建立组** | 1–3 | 交代场地与尺度 | 鸟瞰空镜同机位或高空俯视起手，巨物阵列入画 |
| **接触组** | 2–3 | 强锚定，人物与巨物首次物理接触 | 踩键帽下陷、推杯先晃后倒，微距+浅景深 |
| **推进组** | 3–5 | 连续空间移动 | 跟拍/低角度横移，人快镜稳，景别大跳 |
| **奇观组** | 2–3 | 纯视觉事件提神 | 上帝视角垂直俯拍 / 微距鱼眼 / 极端仰拍 / 环绕 |
| **转折组** | 1–2 | 逻辑或情绪转向 | 硬切 + 巨物遮挡转场 / 瞬间静音 |
| **高潮组** | 1–3 | 撞击、腾空、子弹时间 | 撞击同步进入慢动作，人物悬空旋转、巨物缓倒共享慢速 |
| **落点组** | 1–2 | 金句凝视、结果画面 | 中近景固定或缓拉，英雄镜头式横移，字卡/屏幕文字落版 |
| **一镜到底段** | 1（连续区间） | 单段连续空间叙事 | 全程不断点，靠相机轨迹与主体走位制造推进感 |

**功能 → 组类型映射**：建立→建立组｜引入→接触组｜推进→推进组｜转折→转折组｜高潮→高潮组｜落点→落点组｜视觉事件→奇观组。

## 5. M3 组内结构模板

按镜数选结构：

### 2 镜

- **P 叙述式**：全景/环境 → 特写/细节
  - 例：桌面全景 → 人物踩在键帽边缘的脚部特写
- **Q 反应式**：动作 → 反应
  - 例：人物撞上杯子 → 杯子缓慢倾倒的巨物视角

### 3 镜

- **A 起承式**：环境 → 主体 → 落点
  - 例：鸟瞰桌面 → 人物在键帽间 → 键盘字符微距
- **B 动作链式**：动作1 → 动作2 → 结果
  - 例：助跑 → 起跳 → 落在键帽上溅尘
- **C 反差式**：常规 → 异样 → 揭示
  - 例：看起来普通的桌面 → 木纹被放大成山谷 → 揭示微缩视角
- **K 书写/字卡式**：空白 → 书写中 → 字卡落定（适合标题与金句）

### 4–5 镜

- **D 展开式**：环境 → 动作 → 细节 → 落点 → 反应
- **E 复合式**：A(3镜) + 转场/奇观(1–2镜)

### 专用结构

- **R 转折组**：巨物遮满镜头 → 切 → 新空间第一镜
- **S 奇观组**：上帝视角 → 微距/鱼眼（2–3 镜）
- **T 一镜到底段**：相机关键帧串联（KF0…KFn），主体走位与相机目标绑定

## 6. 组头字段（M3 产出，每组一行）

```
组号 · 组类型 · 锚定句 · 叙事功能(起因/经过/结果) · 情绪走向 · 镜数(含依据)
· 组间衔接 · 连续性锚点 · 本组视觉事件 · 尺度锚定层级 · 强锚定位置
```

| 字段 | 说明 |
|---|---|
| 组号 | G1、G2…… |
| 组类型 | 小人国八组之一 |
| 锚定句 | 本组对应的原句或意思 |
| 叙事功能 | 起因 / 经过 / 结果（三选一或组合，必须齐全覆盖全片） |
| 情绪走向 | 起 → 落（如"平静 → 惊叹 → 释然"） |
| 镜数 | 数字 + M0.5 依据（4 镜 · 4 单元 · 建议 3–5 · 校验合格） |
| 组间衔接 | 动作延续 / 声音桥 / 视线接力 / 硬切 / 巨物遮挡 |
| 连续性锚点 | 与前后组共享元素（巨物/光线/人物着装/空间位置） |
| 本组视觉事件 | 上帝视角 / 微距爆点 / 子弹时间 / 遮挡转场 / 硬光变化 / 英雄镜头 |
| 尺度锚定层级 | 强 / 中 / 弱（全片至少一次强锚定，且不晚于 G2） |
| 强锚定位置 | 具体到镜号（如 G2-镜1 人物踩键帽下陷） |

---

## 7. 组间衔接规则

1. **每个非建立组必须与上一组共享一个连续性锚点**，否则观众跳戏。
2. **连续两组奇观后必须接落点组或接触组**，避免视觉轰炸失去尺度感。
3. **转场切点对齐语义**（转折句处），不对齐时间。
4. **一镜到底段独占全片时**，不需要组间衔接，但需要内部节拍表（见 `03_Cut规则与节奏编排.md` 第 4 节）。
5. **高潮组之后必须给落点组**，不许在高潮处直接结束（除非刻意设计硬切定格）。

---

## 8. 本层反模式

- 组类型与功能不匹配（建立句用了奇观组）。
- 结构镜数超出 M0.5 区间（建议 2–3 镜却用 5 镜 D 结构）。
- 全片没有强锚定，或强锚定晚于 G3。
- 全片没有视觉事件（每组至少命中一个）。
- 连续两组同类型且无落点组隔开。
- 组头字段缺项（尤其"尺度锚定层级"与"本组视觉事件"）。

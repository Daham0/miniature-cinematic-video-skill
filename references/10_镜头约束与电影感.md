# 10 · 镜头约束与电影感（M4–M7 + 电影感八条）

> 来源：分镜策划Skill 约束层（量化）+ 电影感.md（镜头组视觉规则），按小人国尺度改造。
> 本层回答"**在已定的组结构内，镜头具体怎么跳**"。上层是 `09_组级策划引擎.md`，本层不改组类型，只改镜头参数。

## 1. M4 景别标尺（L1–L7）

| 层级 | 景别 | 判定标准 | 小人国用法 |
|---|---|---|---|
| L1 | 大远景 | 人物占画面 <10% | 尺度和奇观宣告（人物在整片键帽阵列中几乎看不见） |
| L2 | 远景 | 人物全身 + 环境，占 10–25% | 建立组起手、上帝视角 |
| L3 | 全景 | 人物全身，占 25–40% | 交代人物与当前巨物的关系 |
| L4 | 中景 | 膝盖以上 | 人物动作链、与巨物互动 |
| L5 | 中近景 | 腰部以上 | 情绪与反应、落点组 |
| L6 | 特写 | 面部/物件局部 | 眼神、手部、巨物局部 |
| L7 | 大特写 / 微距 | 眼睛/纹理/像素级 | **小人国核心武器**：键帽字符、屏幕像素、布纹、灰尘 |

### 量化规则

- **组内至少一对镜头 L 差 ≥2（大跳）**：L6↔L3、L4↔L7 均合格。
- **禁止连续两镜同层级**（L5→L5 直接打回）。
- 避免 L1→L2→L3 的逐级推进（除非刻意设计极缓推拉的一镜到底段）。
- **奇观组允许 L1↔L7 极端跳**（这是小人国最强的视觉签名）。
- **每组必须命中 L7**：全片没有微距就没有小人国。

### 合格示例（4 镜组）

`L6 特写（人物脚踩键帽）→ L2 远景（整片键盘峡谷）→ L4 中景（人物仰头）→ L7 微距（键帽字符被踩出细尘）`
L 差序列：4、2、3 —— 全部 ≥2，合格。

## 2. M5 角度坐标系

### 方位 8 档（水平环绕）

正前 0° / 侧前 45° / 正侧 90° / 侧后 135° / 正后 180° / 侧后 225° / 正侧 270° / 侧前 315°

### 高度 5 档（垂直）

| 档位 | 名称 | 说明 | 小人国价值 |
|---|---|---|---|
| -2 | 贴地仰拍 | 贴桌面/贴地 + 广角仰拍（蚂蚁视角） | **尺度放大器**：巨物像摩天楼 |
| -1 | 低机位仰拍 | 腰以下，仰角 15–30° | 巨物压迫感 |
| 0 | 平视 | 与人物视线同高 | 代入感、情绪 |
| +1 | 高机位俯拍 | 高于视线 | 全局关系、走位 |
| +2 | 上帝视角 | 垂直俯拍（与鸟瞰空镜同机位） | 建立组与奇观组专用 |

### 量化规则

- **组内至少一对镜头角度差 ≥1 档（约 ≥45°）**（方位或高度任一维度）。
- **禁止连续两镜落在"正前 0° + 平视 0 + 中近景 L5"**——这是 AI 的默认舒适区，小人国里出现即平庸。
- **焦段组内至少切换一次**：广角（24–35mm）做尺度与纵深，微距（100mm+）做细节与浅景深。
- 一镜到底段内角度可连续变化，但**变化必须单调**（不许翻来覆去）。

## 3. M6 匹配与转场库

| 转场 | 用法 | 小人国适配 |
|---|---|---|
| 动作匹配 | 动作进行中切 | 起跳瞬间切到腾空 |
| 视线匹配 | 前镜看画外，后镜给内容 | 人物仰头 → 巨大杯沿 |
| 图形匹配 | 形状/线条延续 | 键帽方阵 → 便签格线 |
| 运动方向匹配 | 前后镜同向 | 横移跟拍保持向右 |
| 巨物遮挡转场 | 物体遮满画面时切 | 手指/杯子扫过镜头，最自然 |
| 时间转场 | 压缩时间 | 光线从窗右移到窗左 |
| 硬切 | 情绪冲击、卡点 | 撞击瞬间 |

**规则**：转场切点对齐语义（转折处），不对齐时间；每条视频硬切不超过 3 次，一镜到底方案里为 0。

## 4. M7 轴线规则

- 同组内人物视线/运动方向保持同一侧，禁止无重置的越轴。
- 需要换侧时，必须用一个正后方/过肩镜头，或经转折组、奇观组重置。
- 奇观组与转折组可放宽轴线约束，但仍需方向感连贯。

## 5. 电影感八条（写每个镜头都要过一遍）

### ① 镜头要成组，不要单镜头堆砌

一组镜头要有起因—经过—结果：大场景交代环境与人物位置 → 中景交代人与现场关系 + 微距聚焦动作 → 结果落点（动作结果/情绪反应/字卡）。

### ② 景别必须跳，不能相似

相邻镜头不用相近景别。节奏参考：大远景/全景 → 中景 → 特写 → 微距 → 中近景/结果镜头。禁止"全景接全景""中景接中近景""特写接特写"。

### ③ 机位不能相邻，角度差 >45°

俯视后接平视或仰视；正面后接侧面/过肩/低机位。相邻两镜不许同高度同方位。

### ④ 中景必须有前景或背景，制造景深

中景是交代人与现场关系的关键景别，不能平铺直叙：
- **加前景**：杯沿、笔筒、便签、人物肩膀、植物叶片虚化（小人国里前景巨物虚化同时强化尺度）。
- **加背景**：窗光、屏幕光、走廊纵深、桌面反射。

### ⑤ 大场景主体必须"拉开距离"（四隔离，至少命中两项）

| 隔离方式 | 做法 |
|---|---|
| **颜色隔离** | 人物着装与周围巨物有色相差（暖色人物 vs 冷灰桌面） |
| **距离隔离** | 人物与巨物群保持空间距离，不贴在一堆杂物里 |
| **明暗隔离** | 光比/逆光/局部亮部把人物托出来（窗口光打在人物身上） |
| **构图隔离** | 留白、引导线、巨物框架构图把视线指向人物 |

**小人国专属**：尺度反差本身是最强的隔离手段——但只在**人物与巨物同框且都清晰**时成立，微距浅景深虚掉巨物会让这条失效，所以每段至少留一个"人物全身 + 巨物全貌"的清晰同框镜头。

### ⑥ 微距要"特别大"

微距不是普通特写，是把细节放大到有压迫感：键帽字符的凹刻、屏幕像素网格、木纹缝隙里的灰尘、布料纤维、皮肤汗毛、金属磨损油光。

**判定**：微距镜头必须与前面的大场景形成强烈景别差（L 差 ≥3 才算爆点）。

### ⑦ 一组镜头的开场优先长运镜（要有动机）

- 从大环境推到人物表情特写 → 表达情绪
- 从大场景推到人物手部动作 → 表达"正在做什么"
- 从环境推到巨物/屏幕 → 带出信息或标题

**无动机的运镜 = 炫技**，直接打回。

### ⑧ 超写实只加"一点点"（+10%~20%）

不是做成 CG，而是在真实基础上增加三类细节：

| 类别 | 内容 |
|---|---|
| 材质细节 | 皮肤纹理、汗毛、布料纤维、金属磨损、键帽油光 |
| 光学真实 | 浅景深、反射、逆光、实用光源、轻微颗粒 |
| 环境真实 | 灰尘、水汽、指纹、屏幕像素、自然光衰减 |

**强度红线**：超过 +20% 就变成塑料感 CG，判不合格。**禁止项**：禁止镜头组没有因果只堆空镜；禁止超写实过度变成渲染图。

## 6. 小人国专属镜头语言（默认基调）

```
焦段  ：微距/近摄（等效 100mm 及以上），浅景深，L7 必出
机位  ：低角度贴地/贴桌面为主，人物多在画面下三分之一
透视  ：近大远小强化，前景巨物虚化构成框架
光线  ：日常室内光放大成宏大光源（窗光如舞台灯、台灯如探照灯）
景深  ：主体锐利，前后景巨物边缘柔化
运动  ：人快镜稳——人物动作可快（跑/跳/飞），相机克制（缓推/缓移/跟拍）
```

**反向提示**：微距不是放大镜，禁止人物与巨物同样清晰；禁止全片无 L7。

## 7. 本层自检（写完分镜表逐项打勾）

- [ ] 每组有 L 差 ≥2 的跳切，且无连续同层级
- [ ] 每组至少一个 L7 微距爆点
- [ ] 每组至少一对角度差 ≥45°，无连续舒适区机位
- [ ] 每个中景都有前景或背景
- [ ] 每个大场景镜头都命中至少两项主体隔离
- [ ] 每组开场有动机（长运镜或强锚定）
- [ ] 超写实细节已写明具体类别，强度未超线
- [ ] 组间有连续性锚点，转场切点对齐语义

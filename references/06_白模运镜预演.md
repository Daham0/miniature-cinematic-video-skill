# 06 · 白模运镜预演

> 白模预演是"小人国效果视频"的**空间与时间验证工具**：用 Three.js 白模 HTML 预演相机路径、人物走位、动作节奏与子弹时间，确认后才写最终提示词。
>
> **核心分工：白模管空间与相机，图片管外观。** 白模参考视频不继承人物形象与场景外观；人物形象/场景外观由多视角图和鸟瞰空镜锁定（见 `07_人物形象与场地素材.md`）。

## 1. 白模规格（统一约定）

- **渲染环境**：Three.js（浏览器直接打开 HTML 即可播放），录制用 MediaRecorder 输出 webm。
- **坐标系统**：右手系。相机目标默认原点 `(0,0,0)`；`+X` 右、`+Y` 上、`-Z` 朝向屏幕内。
- **网格辅助**：`AxesHelper` + 原点标记（原点十字/小球），帮助肉眼校验空间关系与机位方向。
- **几何体映射表**（用简单几何体代替真实物体）：

| 真实对象 | 白模几何体 | 建议尺寸 |
|---|---|---|
| 人物 | Capsule（胶囊体）或 Cylinder + Sphere | 高 1（单位） |
| 键帽/巨石 | Box | 约 4-6 单位 |
| 马克杯 | Cylinder（上粗下略细） | 高 6-8 |
| 书本 | Box（薄） | 8×0.5×5 |
| 桌面/地面 | Plane（网格） | 20×20 |
| 障碍/墙体 | Box | 按实际 |

- **颜色约定**：人物 = 暖色（如 0xffaa44），巨物 = 冷灰（0x8899aa），地面 = 深色网格，方便对比。

## 2. 相机关键帧（一镜到底的骨架）

相机运动按**关键帧**定义（位置 + 目标 + 时间）：

```
关键帧列表（示例：桌面穿越一镜到底）：
KF0  t=0.0s  pos(12, 3, 8)    target(0, 0, 0)      —— 高空俯瞰开场
KF1  t=2.0s  pos(8, 1.5, 5)   target(0, 1, 0)      —— 降入桌面高度
KF2  t=5.0s  pos(3, 1.2, 2)   target(1, 1, 0)      —— 贴近人物
KF3  t=8.0s  pos(-2, 1.0, 1)  target(0.5, 1, -1)   —— 穿过键帽间隙
KF4  t=12s   pos(-8, 4, -3)   target(-1, 1, 0)     —— 拉起收尾
```

- 每段移动使用缓动（`CubicBezier` / `smoothstep`），避免生硬直线。
- **穿模检查**：关键帧路径必须与所有几何体保持安全距离（至少 0.3 单位）。
- 相机与主体运动方向必须一致（先定相机动，再排主体动，见 `01_三动原则与五段式结构.md`）。

## 3. 人物走位（主体动）

- 人物胶囊体按"起止点 + 路径点"定义（如 A→B→C），可与相机目标绑定或独立。
- 走位速度 = 路径长度 / 段时长；跳跃用抛物线（上升段 + 下降段）。
- **落点对比**（重要）：预演时在人物落点放一个标记环，验证跳跃弧线终点是否与设计落点一致（见第 8 节）。

## 4. 白模四段模板（构建顺序）

```
段A 场景几何：桌面 Plane + 巨物几何体 + 原点/AxesHelper
段B 相机路径：关键帧列表 + 缓动 + 相机 lookAt
段C 人物走位：人物几何体 + 路径/跳跃/动作时间轴
段D 录制交互：开始/停止按钮 + MediaRecorder 录制 webm
```

## 5. MediaRecorder 录制（产出白模参考视频）

```javascript
// 录制交互（放 HTML 内）
let recorder, chunks = [];
function startRec() { chunks = []; recorder = new MediaRecorder(renderer.domElement.captureStream(60)); recorder.ondataavailable = e => chunks.push(e.data); recorder.start(); }
function stopRec()  { recorder.stop(); recorder.onstop = () => { const blob = new Blob(chunks, {type:'video/webm'}); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = 'white-model-preview.webm'; a.click(); }; }
```

## 6. 几何自检清单（输出白模前自查）

- [ ] 原点与 AxesHelper 可见，相机初始方向可判断
- [ ] 所有巨物有几何体且尺寸比例符合设计
- [ ] 相机关键帧路径无穿模
- [ ] 人物走位起止点与设计一致
- [ ] 时间轴总长与目标视频时长一致（如 12s）
- [ ] 录制按钮可用，能输出 webm

## 7. 给外部模型的附言（当白模要引用外部参考时）

若用户提供了外部参考模型/参考视频作为白模输入，必须在交付说明中附言：
- 白模只借用参考物的**空间结构/机位/节奏**，不继承其主体、外观与背景。
- 若参考视频含人物动作，白模中只提取"运动轨迹与速度曲线"。
- 无法解析的参考（无模型文件、仅视频）→ 手动按参考视频逐秒打关键帧。

## 8. 白模落点对比

**用途**：验证"人物跳跃/被撞飞的落点"是否与设计一致，避免 Seedance 出片后落点漂移。

```
对比方法：
1. 在目标落点放置标记环（RingGeometry 平铺在地面）
2. 预演中人物落地瞬间检查：落点与标记环偏差 ≤ 0.3 单位
3. 偏差过大 → 调整速度/抛物线参数重跑
4. 确认后把落点坐标写进视频提示词（如"人物落在键帽B正中心"）
```

## 9. 一镜到底 + 子弹时间（timeWarp 时间重映射）

子弹时间 = 真实时间 t 到动画时间 τ 的重映射。核心：

```
时间轴设计：
- 真实时间 t：0→12s（视频物理时长）
- 动画时间 τ = timeWarp(t)：正常段 τ=t；子弹时间段 τ 以 0.15 倍速推进
- 过渡段 0.5-0.7s 平滑变速（速度 1 → 0.15 → 1）
```

### 实现骨架（HTML 内）

```javascript
// timeWarp：真实t → 动画τ
function timeWarp(t, events) {
  // events: [{t0, t1, speed}]  按段叠加
  let tau = 0, prev = 0;
  for (const e of events) {
    const seg = Math.min(Math.max(t - e.t0, 0), e.t1 - e.t0);
    tau += seg * e.speed;
    if (t <= e.t1) break;
  }
  return tau;
}
// 动画取值：actor.position = computeActor(tau)；杯旋转 = computeCupRotation(tau)
```

- **子弹时间与撞击同步**：撞击点设为子弹时间起点（`τ2.5`），人物悬空自转 + 巨物缓慢倾倒共享慢动作。
- 白模验证通过后，把时间重映射写进提示词：
  `0-3秒正常速度，3-6秒进入子弹时间（慢动作），6-12秒恢复正常；人物撞击后悬空缓慢旋转，杯子在慢动作中倒下。`
- **首帧锁定的三件套**（锁定视角时）：① 首帧模式而非参考图模式；② 提示词写"固定机位/一镜到底/无剪辑/无视角跳变"；③ 负面约束显式列出"不出现环绕/穿越/子弹时间/多镜头/切到……"。**首帧图只锁第 0 帧，不锁全片。**

## 10. 白模 HTML 模板

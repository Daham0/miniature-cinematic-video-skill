```
第1道 叙事层 → 意思对不对（组、因果、锚定句）
```

## 第1道｜叙事层（组与因果）

- [ ] 每个语义单元恰好对应一组（一句话没被拆到两个镜头里讲）
- [ ] 每组都有明确的叙事功能（建立/引入/推进/转折/高潮/落点）
- [ ] 全片覆盖"起因—经过—结果"三段，不缺结果
- [ ] 每组至少一个视觉事件（上帝视角/微距爆点/子弹时间/遮挡转场/硬光/英雄镜头）
- [ ] 组间有连续性锚点（道具/光线/着装/位置），无跳戏
- [ ] 联想的画面能追溯到文案原词，凭空补的已标"设计补充"
- [ ] 没有命中俗套黑名单（下雨=悲伤、时钟=时间、飞鸟=自由……）

**打回动作**：改 `09_组级策划引擎.md` 对应 M1/M2/M3 层，只重组头，不动镜行。

## 第2道｜镜头层（跳切与构图）

- [ ] 组内至少一对 L 差 ≥2，无连续两镜同层级
- [ ] 组内至少一对角度差 ≥45°，无"正前+平视+L5"连续舒适区
- [ ] 每个中景有前景或背景
- [ ] 每个大场景命中至少两项主体隔离（颜色/距离/明暗/构图）
- [ ] 每组开场有动机（长运镜有明确落点或强锚定）
- [ ] 焦段组内至少切换一次（广角 ↔ 微距）
- [ ] 越轴处有重置镜头
- [ ] 转场切点对齐语义转折，硬切次数 ≤3

**打回动作**：改 `10_镜头约束与电影感.md` 对应的 M4/M5/M6/M7 参数，不动组结构。

## 第3道｜尺度层（小人国是否成立）

- [ ] 第 1–2 秒内出现可辨识巨物，观众能立刻读出"人物很小"
- [ ] 全片至少一次**强锚定**（人物与巨物直接物理接触），且不晚于 G2
- [ ] 全片人物与巨物比例统一，无忽大忽小
- [ ] 巨物之间相对尺寸正确（键帽 < 杯子 < 书本，不乱）
- [ ] 每组至少一个 L7 微距爆点，且与大场景 L 差 ≥3
- [ ] 每镜至少 2 个物理细节（接触 + 重力/惯性保底）
- [ ] 关键动作有完整因果链：起因动作 → 运动过程 → 碰撞结果
- [ ] 巨物有反应（下陷/晃动/倾倒/溅尘），不是死的背景板
- [ ] 至少一个"人物全身 + 巨物全貌"的清晰同框镜头（证明尺度）
- [ ] 超写实强度在 +10%~20%，无 CG 塑料感

**打回动作**：改 `02_尺度锚定与物理细节.md` 相关字段（锚定层级、物理细节、微距爆点），或回 `09` 调整强锚定位置。

## 反模式总表（命中即不合格）

### 叙事类

| 反模式 | 症状 | 修法 |
|---|---|---|
| 空镜堆叠 | 镜头都好看但没故事 | 回 M1 补节拍功能，每组锁一个视觉事件 |
| 一句拆两镜 | 台词跨镜讲完 | 并镜或改锚定句 |
| 组类型错配 | 建立句用了奇观组 | 按 M2 映射表重选 |
| 结构超区间 | 建议 2–3 镜却用 5 镜 | 按 M3 换结构模板 |

### 镜头类

| 反模式 | 症状 | 修法 |
|---|---|---|
| AI 同质化 | 连续中近景平视正面 | 强制 L 差 ≥2 + 角度差 ≥45° |
| 景别滑行 | L1→L2→L3 逐级推 | 改成大跳，只留一镜过渡 |
| 平铺中景 | 中景无前景无景深 | 加前景巨物虚化或背景纵深 |
| 主体淹没 | 大场景找不到人物 | 四隔离至少做两项 |
| 无动机运镜 | 推拉没落点 | 给运镜一个终点（表情/手部/字符/屏幕） |
| 微距不够大 | 特写当微距用 | 换 L7，L 差 ≥3 |

### 尺度类（小人国致命项）

| 反模式 | 症状 | 修法 |
|---|---|---|
| 比例漂移 | 人物忽大忽小 | 统一比例 + 每段强锚定 |
| 巨物不动 | 像贴图背景 | 每镜补一个巨物反应 |
| 悬浮失重 | 跳跃没弧线 | 抛物线 + 落地缓冲蹲身 |
| 轻易举巨物 | 小人抬起杯子 | 改成推动/撬动/被反作用力弹开 |
| 全片无微距 | 像普通微缩摆拍 | 每组补 L7 |
| CG 塑料感 | 材质过干净 | 超写实回落到 +10~20%，补灰尘/磨损/指纹 |

### 出片类

| 失败现象 | 原因 | 修法 |
|---|---|---|
| 人物形象漂移 | 身份锚不足 | 补 P1-P4，首句重申"与@图片P1完全一致" |
| 尺度感丢失 | 锚定太晚 | 段1就出现人物与巨物接触，负面加"比例一致" |
| 视角跳变 | 提示词含运镜词/首帧未锁 | 锁机位三件套 + 负面禁词（见 `06` 第9节） |
| 穿模 | 相机路径撞物体 | 过预演门，路径留 ≥0.3 单位安全距 |
| 480P 糊 | 细节密度过高 | 降细节、增主体占比、简化背景 |
| 光效盖主体 | 体积光过强 | 负面加"人物主体锐利清晰，光效不遮挡人物" |
| 子弹时间失效 | 时间段没写死 | 明确"0-3正常 / 3-6慢动作0.15倍 / 6-12正常"+撞击同步 |
| 中文乱码 | 键帽写中文 | 字符改数字/简单图案 |

## 一票否决项（出现任一条，直接打回重做，不接受局部修改）

1. 全片没有强锚定，观众看不出来人物是小人。
2. 全片没有 L7 微距。
3. 镜头之间没有因果，纯空镜堆叠。
4. 提示词缺【反向屏蔽规则】或署名水印。
5. 白模参考被当作画面参考投喂。

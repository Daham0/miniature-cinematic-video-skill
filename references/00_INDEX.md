# 小人国电影感出片Skill · 知识库总索引

本知识库是素材库，SKILL.md 的门禁是调度器。按任务需求**只读需要的文件**，禁止一次性灌入全部内容。

三个源融合后的分工：01–08 是主干（小人国出片流水线），**09–11 是融合层**（组级策划 + 镜头约束与电影感 + 三方质检）。

## 读取路线（按七门推进）

```
门1 形象门 → 07（人物多视角图 + P1-P4 引用规则）
门2 场地门 → 07（鸟瞰空镜）+ 05（场景九大域与可插拔模块）
门3 规格门 → 08（尺寸/时长/平台规格）
门4 方案门 → 09（M0–M3 组级策划，产方案骨架）+ 08（A/B/C/D 差异化维度与版本卡）
门5 分镜门 → 10（M4–M7 量化约束 + 电影感八条）+ 03（Cut与节奏）+ 11（四道质检）
门6 预演门 → 06（白模规格/坐标/相机/子弹时间/落点对比）
门7 出片门 → 01（三动）+ 02（尺度锚定与物理细节）+ 04（白描纪律）+ templates/视频提示词模板.md
```

## 防污染声明

三份**输出标准**永不被知识库污染：

1. 设计镜头与节奏 → `03_Cut规则与节奏编排.md` + `09_组级策划引擎.md`
2. 写提示词（白描 + 逐秒节拍） → `04_文案视觉化与白描纪律.md`
3. 提示词范文格式 → `templates/视频提示词模板.md`

01/02/05/06/08/10/11 是"拍什么、怎么设计、怎么验收"的决策输入，不得改变输出格式。

# 04 · 文案视觉化与白描纪律

> 小人国视频的提示词必须"看得见、拍得成"。这一章解决：把一句话文案变成可执行的画面语言。

## 1. 文案视觉化四层

任何文案/想法都要经过四层翻译，才能变成镜头语言：

```
字面层  → 这句话讲了什么事实（名词/动作/状态）
动作层  → 人物要做什么动作（动词 → 身体分解）
尺度层  → 在小人国尺度下如何呈现（巨物对比/微距视角）
情绪层  → 这段要什么情绪（紧张/冲击/喜剧/释然）
```

### 示例：文案"他在键盘上奔跑"

```
字面层：一个人物在键盘上跑
动作层：双脚交替迈步、手臂摆动、身体前倾
尺度层：键帽如巨石，他在键帽顶面奔跑，键帽间隙如峡谷
情绪层：紧张而自由（低机位跟拍，风吹衣角）
```

## 2. 白描纪律（最高优先级）

### 只写五类可验证内容

```
可见   ：颜色、形状、位置、大小（"白色马克杯，直径约人物身高三倍"）
可拍   ：机位、景别、焦段（"低角度微距，等效100mm"）
可运动 ：位移、速度、方向（"从画面左侧向右奔跑"）
可验证 ：因果链（"推倒 → 倒下 → 溅尘"）
可听感 ：用画面节奏表达声音（"落地顿挫"）
```

### 禁用词表（不可执行词）

```
高级感、震撼、氛围拉满、宿命感、史诗感、唯美、大气、电影质感（空洞时禁用）
自然真实、物理正确（空洞时禁用）
让人惊叹、视觉冲击（作为形容词禁用，必须写具体画面）
```

### 白描替换表

| 空洞表达 | 白描替换 |
|---|---|
| 震撼的场面 | 一排键帽如楼群，人物站在键帽顶边缘 |
| 很有速度感 | 人物俯身疾跑，衣摆后飘，身后灰尘扬起 |
| 温暖氛围 | 午后斜阳从窗户射入，光线里有浮尘 |
| 巨物压迫 | 马克杯占据画面左侧2/3，人物在杯底如豆 |

## 3. 动词 → 身体分解表

写人物动作时，把动词分解成身体可执行的动作链：

| 动词 | 身体分解（提示词写法） |
|---|---|
| 跑 | 双脚交替迈步、身体前倾、双臂摆动、衣摆后飘 |
| 跳 | 屈膝蓄力 → 蹬地腾空 → 身体伸展 → 抛物线 → 屈膝落地缓冲 |
| 推 | 双手抵住巨物 → 身体前倾发力 → 巨物晃动/倒下 → 人物顺势前冲 |
| 撞 | 高速前冲 → 接触瞬间身体后仰 → 被弹开/甩飞 → 空中翻腾 |
| 爬 | 双手抓住边缘 → 手臂发力上拉 → 翻身上顶 → 站立张望 |
| 停 | 急停时身体前倾 → 双脚滑动 → 站稳 → 喘气/回望 |
| 飞 | 腾空 → 身体展开 → 空中旋转 → 减速悬停/下落 |

> 每个动作至少 3 个分解环节，写进提示词才能让 Seedance 2.5 生成连贯动作。

## 4. 情绪映射库（情绪 → 镜头语言）

| 情绪 | 镜头语言 |
|---|---|
| 好奇 | 中景缓推，人物探头张望，镜头缓慢靠近 |
| 紧张 | 低机位跟拍，人物快速移动，灰尘扬起，巨物阴影逼近 |
| 冲击 | 快速推进/硬切，碰撞瞬间，巨物反应剧烈 |
| 喜剧 | 荒诞比例，人物与巨物反差（如小人奋力推不动一片薯片） |
| 释然 | 全景缓拉，人物停下回望，环境静止，光线柔化 |
| 孤独 | 大远景，人物极小，巨物环绕，画面留白多 |
| 自由 | 跟拍运动，人物奔跑/飞翔，环境在身后退去 |

## 5. 提示词结构模板（白描 + 五步逻辑）

每段视频提示词按以下顺序组织：

```
① 全局视听DNA（画风/光线/镜头语言基调）
② 人物设定（引用@图片X 人物多视角图，外貌/服装）
③ 场地设定（引用@图片X 鸟瞰空镜，场景布局/尺度）
④ 分段镜头描述（五段式 + Cut六要素 + 逐秒节拍）
⑤ 反向屏蔽规则（硬负面）
⑥ 署名水印（由@拍广告的Daham 独家定制，微信：Daham0927...）
```

完整模板见 `templates/视频提示词模板.md`。

## 6. 输出防污染

- 知识库只提供"拍什么、怎么设计"，输出始终按本模板骨架。

# 08 · 风格方案路由与平台规格

> 门3（规格）与门4（方案）的执行细则。

## 1. 平台规格（硬性，SKILL.md 规则c/d）

| 项目 | 规格 |
|---|---|
| 视频模型 | **Seedance 2.5** |
| 视频分辨率 | **480P** |
| 图片模型 | **GPT Image2.5** |
| 图片分辨率 | **1K** |
| 人物图比例 | **3:4 竖屏** |
| 视频尺寸 | **16:9 横屏 或 9:16 竖屏**（每次生成前必问；未答默认 **16:9 横屏**） |
| 单段时长 | 默认 12s，Seedance 2.5 上限 30s |

### 尺寸询问话术（每次生成前必问）

> 本次视频的尺寸用 **16:9 横屏** 还是 **9:16 竖屏**？未回答默认 16:9 横屏。

- 竖屏（9:16）：适合短视频平台/手机观看，人物多处于画面中下部，巨物纵向延伸。
- 横屏（16:9）：适合 TVC/横屏平台，画面横向空间大，适合一镜到底横向穿越。

## 2. 风格方案路由（门4）

写完整提示词前，必须给差异化方案（3-5 个），每方案 ≤8 行：

### 方案 A：超写实（默认，风险最低）
```
视角：低角度微距 + 浅景深，真实桌面纹理
画面：人物与巨物严格同尺度，物理细节完整
冲击力：★★  执行难度：★
一句话：真实到以为是小人国纪录片
```

### 方案 B：超现实魔幻
```
视角：微距 + 特殊光效（丁达尔光束/体积光/环境辉光）
画面：巨物材质升维（键帽如琉璃、灰尘如星尘）
冲击力：★★★  执行难度：★★
一句话：小人国世界的梦境版
```

### 方案 C：荒诞无厘头
```
视角：常规机位 + 喜剧节奏（顿挫/反转）
画面：人物与巨物的反差笑点（小人推不动一片薯片、被豆子砸晕）
冲击力：★★★  执行难度：★★
一句话：喜剧逻辑主宰小人国
```

### 方案 D：高速穿越（视觉冲击最强）
```
视角：FPV/超广角 + 运动模糊 + 子弹时间
画面：人物高速冲过键帽峡谷、撞翻咖啡杯进入子弹时间
冲击力：★★★★★  执行难度：★★★★
一句话：把小人国拍成动作大片
```

### 方案选择规则

- 用户没指定 → 默认给 A/B/C/D 四案，推荐 B 或 D。
- 用户指定"冲击力/炫酷/大片" → 主推 D（必须过门5 白模预演）。
- 用户指定"真实/自然" → 主推 A。
- 用户要"都要" → 每案独立成片，不混在一个视频里。

## 3. 版本卡（方案确认后输出）

用户选定方案后，先输出版本卡再写提示词：

```
【版本卡】
方案：B 超现实魔幻
尺寸：16:9 横屏（默认）
时长：12s
风格：微距 + 体积光 + 琉璃质感
人物：@图片P1-P4（身份锚）
场地：@图片X 鸟瞰空镜（空间锚）
主镜头：人物在键帽峡谷奔跑，灰尘如星尘扬起
节奏：0-3s建立 / 3-7s推进 / 7-9s子弹时间 / 9-12s收尾
风险点：光效可能盖过尺度感 → 负面约束加"人物清晰锐利"
```

## 4. Seedance 2.5 能力卡（写提示词时参考）

| 能力 | 用法 |
|---|---|
| 一镜到底 | 写"一镜到底/无剪辑/无视角跳变"，时间区间连续 |
| 子弹时间/慢动作 | 写"进入子弹时间/慢动作0.15倍"，配时间重映射描述 |
| 参考图 | `@图片X` 引用人物多视角图/鸟瞰空镜；首帧/参考图模式分开写 |
| 多镜头 | 用连续时间区间分段（0-3/3-6/6-9）表达硬切 |
| 文字/字符 | 键帽字符尽量写简单图案或数字，避免中文乱码 |
| 480P | 提示词中的细节密度适配低分辨率：大色块+清晰轮廓，避免过细纹理 |

## 5. 失败模式修复库

| 失败现象 | 修复动作 |
|---|---|
| 人物形象漂移 | 补足 P1-P4，提示词开头重申"人物外貌服装与@图片P1完全一致" |
| 尺度感丢失 | 强锚定前置（段1就出现人物与巨物接触），负面加"比例一致" |
| 视角跳变 | 锁机位三件套 + 负面禁词（见 `06_白模运镜预演.md` 第9节） |
| 穿模 | 过门5 白模预演，调整相机路径 |
| 画面模糊（480P） | 降细节密度、增大主体占比、简化背景 |
| 光效盖过主体 | 负面加"人物主体锐利清晰，光效不遮挡人物" |
| 子弹时间失效 | 明确写时间段（0-3正常/3-6慢动作/6-12正常）+ 撞击同步 |

## 6. 运镜术语表（提示词白描用）

| 术语 | 白描含义 |
|---|---|
| 缓推 | 相机沿视线方向缓慢前进，画面由远及近 |
| 缓拉 | 相机后退，画面由近及远，交代环境 |
| 左移/右移 | 相机水平横移，平行于地面 |
| 跟拍 | 相机与主体保持相对距离同步移动 |
| 低角度 | 相机贴近地面/桌面，仰视人物与巨物 |
| 高空俯视 | 相机在场景上方垂直向下（与鸟瞰空镜同机位） |
| 微距特写 | 等效100mm+，浅景深，主体充满画面 |
| FPV | 第一人称视角，模拟人物视点快速穿行 |

## 7. 全局光影模板（小人国默认光线）

```
默认：午后室内自然光，从画面左侧窗户射入，暖白调，光线中有浮尘微粒
变体1：台灯探照光（夜晚桌面，光束如舞台灯，人物在光圈中）
变体2：冷调顶光（科技感，数码域场景）
变体3：晨光逆光（户外域，人物剪影轮廓光）
```

# 05 · 场景扩展与可插拔模块

> 小人国效果的核心是"人小物大"。场地（巨物世界）决定视频的视觉奇观上限。本章提供场景扩展体系与场地素材生成规则。

## 1. 场景扩展九大域（小人国世界从哪来）

把日常物体放大成"小人国世界"，按领域划分：

| 域 | 场景示例 | 巨物元素 | 典型氛围 |
|---|---|---|---|
| 办公域 | 桌面/键盘/鼠标/便签 | 键帽如楼群、笔如桥、订书机如坦克 | 现代冷调 |
| 餐饮域 | 餐桌/零食/饮品 | 薯片如山、咖啡杯如塔、面包如丘陵 | 温暖食物感 |
| 居家域 | 床/沙发/地板/书架 | 枕头如山、拖鞋如船、书本如悬崖 | 亲切松弛 |
| 文具域 | 桌面文具/纸张 | 钢笔如树干、橡皮如巨石、纸张如平原 | 清新明亮 |
| 数码域 | 手机/平板/电脑 | 屏幕如广场、充电线如藤蔓、摄像头如巨眼 | 未来科技 |
| 厨房域 | 灶台/餐具/食材 | 锅如湖泊、菜叶如森林、调料瓶如灯塔 | 烟火气 |
| 户外域 | 花坛/草地/沙地 | 草叶如森林、石子如山丘、水洼如海洋 | 自然野趣 |
| 玩具域 | 乐高/积木/玩偶 | 积木如楼、玩偶如巨人同伴 | 童趣荒诞 |
| 混合域 | 以上多域叠加 | 桌面+食物+数码混搭 | 超现实 |

## 2. 场景分类路由表（用户需求 → 场景域）

用户只说"小人国"没给场地 → 默认办公域（键帽/桌面，最易出效果）。

| 用户线索 | 路由到 |
|---|---|
| 桌面/键盘/办公 | 办公域 |
| 零食/咖啡/食物 | 餐饮域 |

## 3. 场景参考图解析（用户提供场地图时）

用户给了场地参考图（一张真实桌面/场景照片）：
1. **解析空间布局**：主体物位置、视线方向、主光源。
2. **提取巨物清单**：有哪些可放大的物体（键帽/杯子/书本/零食）。
3. **确定尺度基准**：选一个物体作为"人物参考物"（如人物身高 ≈ 杯子高度 1/5）。
4. **生成鸟瞰空镜**：按参考图布局生成垂直向下俯视 90° 空镜（见 `07_人物形象与场地素材.md`）。
5. **写提示词时引用**：`@图片X 为场地鸟瞰空镜，锁定场景布局与尺度`。

## 4. 场地素材硬规则（与 SKILL.md 规则e 对应）

- 每次生成视频**必须**有场地素材：一张**鸟瞰视角（垂直向下俯视）空镜**。
- 空镜提示词必须**显式体现机位**："垂直向下俯视 90°""鸟瞰空镜""top-down view"。
- 空镜作用：锁定场地全局布局、巨物分布、地面材质、光线方向。
- 空镜不替代人物多视角图；二者缺一不可（素材双件套）。

## 5. 模块调用规则 S1-S6（可插拔场景组合）

场景作为可插拔模块，按规则组合：

```
S1 单域单景   ：一个场景域，一个主巨物（默认，风险最低）
S2 单域多景   ：一个场景域，多个巨物组成群组（键帽阵列）
S3 多域拼接   ：两个场景域通过运动过渡（桌面→食物）——需白模预演验证路径
S4 巨物动态   ：场景内巨物参与动作（杯子倒下、书页翻动）——环境动强化
S5 尺度穿越   ：人物尺度在段落间变化（变大/变小）——高风险，方案里显式说明
S6 人物与场景共生：人物在巨物上"生活"（在键帽上搭帐篷）——多镜头系列
```

- 默认用 S1；用户要求丰富/高级时升级到 S2-S3。
- S3-S5 必须过门5（白模预演门）验证相机路径与尺度变化。
- 每次只调用一个主模块，副模块最多 1 个，避免场景过载。

## 6. 场景空镜 + 人物多视角图的组合规则（门2 落地）

写视频提示词时：
```
场地：引用@图片X（鸟瞰空镜），场景为<域>，巨物为<清单>，尺度基准为<人物≈巨物高度比例>
人物：引用@图片P1-P4（人物多视角图），外貌服装锁定
机位：低角度微距，依据鸟瞰空镜的空间布局选择视线方向
```

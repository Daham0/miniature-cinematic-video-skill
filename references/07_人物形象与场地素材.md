# 07 · 人物形象与场地素材

> 小人国视频的素材双件套：**人物多视角图（身份锚）+ 场地鸟瞰空镜（空间锚）**。缺一不可。

## 1. 人物多视角图（P1-P4）

### 硬性规格（SKILL.md 规则a/b）

- **启动先收集**：每次任务开始必须先询问用户是否提供个人形象图片。
- **用户提供** → 直接使用；视角不全时用 GPT Image2.5 补足缺失视角。
- **用户未提供** → 生成 **4 视角灰底纯色背景图**：

| 编号 | 视角 | 说明 |
|---|---|---|
| P1 | 半身正面对镜头 | 用于面部/服装识别 |
| P2 | 左侧对镜头 | 用于侧面轮廓/走位 |
| P3 | 右侧对镜头 | 用于侧面轮廓/走位（镜像参考） |
| P4 | 全身效果 | 用于全身比例/动作 |

- 图片尺寸：**3:4 竖屏**。
- 分辨率：**1K**。
- 生成模型：**GPT Image2.5**。
- 背景：**灰底纯色**（浅灰/中灰单色背景，无场景信息，保证人物主体干净可识别）。

### 人物一致性引用规则

写视频提示词时统一引用：

```
人物：引用@图片P1/P2/P3/P4（人物多视角图），外貌、服装、发型、体型完全一致
```

- 多视角图是人物外观唯一来源；视频里的人物形象必须与 P1-P4 一致。
- 每次出片必须携带 P1-P4（至少 P1+P4），缺视角时补足后再出片。

## 2. 场地鸟瞰空镜

### 硬性规格（SKILL.md 规则e）

- 每次生成视频必须有**一张场地空镜图片**。
- 空镜机位：**鸟瞰视角（垂直向下俯视 90°，top-down）**。
- 提示词**必须显式体现该机位**：写"垂直向下俯视 90°""鸟瞰空镜""top-down view"。
- 规格同图片硬规则：GPT Image2.5、1K、3:4 竖屏（人物图）或 16:9/9:16（按出片尺寸）。

### 空镜内容要求

```
必须包含：
- 场地全局布局（桌面/地面/平台轮廓）
- 巨物清单及分布（键帽阵列/杯子/书本/零食等）
- 地面材质（木纹/布纹/纸张/键帽字符）
- 光线方向（哪边亮哪边暗，为后续机位定光）
- 尺度基准提示（如"人物将在键帽间隙中奔跑"）

禁止包含：
- 人物本体（空镜必须是"空"的，为人物留出表演空间）
- 杂乱无关物品
```

### 空镜提示词模板（见 templates/场地鸟瞰空镜提示词模板.md）

## 3. 素材双件套检查表（出片前必过）

- [ ] 有人物 P1-P4（至少 P1 + P4，建议全 4 张）
- [ ] 人物图符合 3:4 竖屏、灰底纯色、1K、GPT Image2.5
- [ ] 有场地鸟瞰空镜（垂直向下俯视 90°，提示词显式体现机位）
- [ ] 空镜含巨物清单与地面材质
- [ ] 尺寸询问已确认（16:9 / 9:16，未答默认 16:9）

## 4. 素材补充规则

- 用户给了一张普通人物照（无侧面/全身）→ 用 GPT Image2.5 生成 P2/P3/P4 补全。
- 用户只给了场景照片 → 按照片布局生成鸟瞰空镜。
- 用户什么素材都没给 → 按门1 生成人物四视角，按门2 生成鸟瞰空镜（默认办公域，见 `05_场景扩展与可插拔模块.md`）。

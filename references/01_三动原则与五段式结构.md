# 01 · 三动原则与五段式结构

> 小人国效果视频的叙事发动机。**任何镜头都必须回答：这一秒谁在动、谁跟着动、谁被动。**

## 1. 三动原则（核心方法论）

小人国效果的"活"来自三层运动叠加，按优先级排序：

```
第一动：相机动（Camera Move）—— 机位、视角、焦点的运动
第二动：主体动（Subject Move）—— 人物/主角的运动
第三动：环境动（Environment Move）—— 场景中巨物的运动/反应
```

### 层级规则

- **先定相机动，再排主体动，最后补环境动**。顺序不可颠倒。
- **相机动是基调**：锁定机位则全段固定，运动机位则全段按曲线推进。相机动与主体动方向必须一致，禁止"锁定机位+快速环绕"类冲突指令。
- **主体动是叙事**：人物的动作是观众注意力的锚点。
- **环境动是验证**：巨物（键帽、杯子、书本、食物）的轻微位移、倒下、被触碰，用来证明"人物真的小"。环境动是尺度感的第二重保险。

### 三动写法公式（每个镜头必填）

```
相机：<机位/焦段/运动轨迹>（如"低角度微距，从桌面右侧缓慢左移"）
主体：<人物动作>（如"人物双手推倒一枚键帽"）
环境：<巨物反应>（如"键帽倒下砸起一小团灰尘"）
```

### 节奏前置

**先定节奏表，再写画面**。节奏决定情绪，画面填充节奏。默认节奏设计顺序：
文案拆分 → 每段情绪曲线 → 每段时长 → 每段主运动 → 每段机位。

## 2. 五段式输出结构

一段完整的小人国视频（建议 10-12s，Seedance 2.5 单段上限 30s）按五个叙事段组织：

```
段1｜建立（0-2s）    ：尺度锚定 + 环境建立。先让观众看清"这是桌面/食物/键盘的巨大世界"
段2｜引入（2-4s）    ：人物出场。用与巨物的对比动作（推、爬、跑、飞）确认人物尺度
段3｜推进（4-8s）    ：核心事件。一个完整动作链（跑→跳→撞→飞），情绪高峰
段4｜回落（8-10s）   ：动作结果。巨物反应 + 人物状态，给出因果闭环
段5｜收尾（10-12s）  ：定格/留白。人物停住、环境静止，或一个钩子动作
```

### 五段式设计规则

- 每段有且只有一个**情绪关键词**（好奇→紧张→冲击→释然→回味）。
- 每段的秒数可以浮动，但**五段结构必须完整**，禁止只有高潮没有建立。
- 段与段之间用接法标签（〔连续〕〔硬切〕，见 `03_Cut规则与节奏编排.md`）衔接。

## 3. 输出前的导演顺序（防漏项）

```
任务类型判断（小人国/巨物对比/微缩世界？）
  → 素材检查（人物多视角图？场地鸟瞰空镜？缺则回到门1/门2）
  → 规格确认（16:9 / 9:16？时长？——门3 必问）
  → 阶段结构（五段式）
  → 镜头拆分（Cut 六要素）
  → 节奏设计（逐秒节拍）
  → 三动填充（相机动/主体动/环境动）
  → 负面约束（反向屏蔽规则）
```

## 4. 示例：10s 小人国开场结构

```
段1 建立 0-2s  ：桌面微距，一排巨大键帽占据画面，光线从左侧斜射
段2 引入 2-4s  ：人物从键帽间隙跑出，站在一枚键帽边缘张望（尺度锚定）
段3 推进 4-7s  ：人物助跑起跳，从键帽A跃向键帽B，空中翻腾
段4 回落 7-9s  ：人物落在键帽B上，键帽微微下陷（环境动），溅起细小灰尘
段5 收尾 9-10s ：人物回望起点，风吹过桌面，发丝与衣角轻动
```

> 每段的秒数必须写进提示词（`镜头N：X~X秒` 或连续时间区间 `0-3秒`），Seedance 2.5 使用连续时间区间。

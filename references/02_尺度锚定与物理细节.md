# 02 · 尺度锚定与物理细节

> 小人国效果成立的前提：**观众必须在第 1-2 秒就相信"人物真的很小"**。尺度锚定 + 物理细节 + 负面约束三件套。

## 1. 尺度锚定（Sizing Anchor）

### 什么是尺度锚定

用**可辨识的日常巨物**作为参照系，让观众瞬间读懂人物尺度。小人国世界的"尺子"必须是观众熟悉尺寸的物体：键盘键帽、马克杯、书本、手机、水果、零食、文具、桌面摆件。

### 锚定层级（从强到弱）

```
强锚定：人物与巨物直接接触（站在键帽上、推倒杯子、爬过书本边缘）
中锚定：人物与巨物同框对比（人物在杯子旁、在手机屏幕上奔跑）
弱锚定：环境特征暗示（桌面木纹、纸张纹理、布料纤维放大成"地面"）
```

- 每段视频**至少出现一次强锚定**，最好在段1/段2（建立与引入阶段）。
- 锚定物必须**纹理真实**：木纹、布纹、纸张、键帽字符、屏幕像素——放大的日常质感是小人国视觉的核心。

### 尺度一致性规则

- 同一视频内，所有巨物与人物保持**同一尺度比例**（如人物≈键帽高度的 1/3，则全片不变）。
- 巨物之间也保持正确相对尺寸（键帽 vs 杯子 vs 书本文案大小关系不乱）。
- 人物身高比例前后一致，禁止同段内忽大忽小（除非是刻意设计的尺度穿越，但要在方案里显式说明）。

## 2. 微距摄影基调（小人国默认镜头语言）

```
焦段      ：微距/近摄视角（等效 100mm 微距及以上），浅景深
机位      ：低角度贴地/贴桌面，人物处于画面下三分之一
透视      ：近大远小强化，前景巨物虚化构成框架构图
光线      ：日常室内光放大成"宏大光源"（窗户光如舞台灯、台灯光如探照灯）
景深      ：主体锐利，前景/背景巨物边缘柔化
运动      ：缓慢推移为主，速度感靠主体动作表达（人快、镜稳）
```

- **微距不是放大镜**：禁止把人物和巨物都拍成同样清晰，微距的浅景深是尺度感的放大器。
- **人快镜稳**：人物动作可以快（跑、跳、飞），相机运动要克制（缓推、缓移、跟拍）。

## 3. 物理细节清单（验证"真实小人国"）

写提示词时，按物理细节清单自查，能写进提示词的都写：

| 类别 | 细节示例 |
|---|---|
| 接触 | 人物踩在键帽上，键帽轻微下陷；推杯子时杯子先晃再倒 |
| 重力 | 跳跃有抛物线下落，落地有缓冲蹲身；抛出的东西有弧线 |
| 惯性 | 急停时身体前倾；被甩飞后有一段滑行 |
| 碰撞 | 撞到巨物时巨物有反应（晃动、倒下、溅尘）；人物会被反作用力弹开 |
| 灰尘/微粒 | 桌面灰尘在人物跑动时扬起；巨物倒下时震起微尘 |
| 材质 | 布料纤维、纸张毛边、键帽字符、屏幕像素在微距下清晰可见 |
| 声音感 | 通过画面表现（动作的节奏感、碰撞的顿挫），提示词写动作节奏即可 |
| 光影 | 人物在巨物上投下细小阴影；巨物在人物身后投下巨大阴影（尺度反差强化） |

### 物理细节写作原则

- 每个镜头至少 2 个物理细节（接触 + 重力/惯性至少保底）。
- 物理细节用**具体动词**写："下陷""倾倒""溅起""弹开"，不写"真实感""物理自然"。
- 关键动作（跳跃、撞击、飞落）必须写**完整因果链**：起因动作 → 运动过程 → 碰撞结果。

## 4. 负面约束（反向屏蔽规则）

### 写法要求

- **正向契约优先，硬负面单独成段**【反向屏蔽规则】。
- 模型对"不要 X"响应很差，弱否定会召唤 X。先写清"要什么"，再列硬约束。
- **锁定视角时切忌在提示词里出现触发视角变化的禁用词**：环绕、穿越、子弹时间、多镜头、切到……（除非刻意设计，如方案D高速穿越）。

### 小人国专属反向屏蔽模板

```
【反向屏蔽规则】
1. 不出现人物与巨物比例失调（人物不得忽大忽小）
2. 不出现机位跳变、视角突然切换（保持一镜到底/固定机位）
3. 不出现镜头穿模（相机穿过物体/人物）
4. 不出现"环绕"“穿越”"子弹时间"等未设计的运镜词
5. 不出现手指、拍摄设备、现实环境穿帮
6. 不出现人物悬浮失重（除非设计为慢动作/子弹时间）
7. 不出现巨物被人物轻易举起（尺度比例失衡）
8. 不出现文字错乱、键帽字符乱码
```

### 常见失败模式自查

| 失败现象 | 原因 | 修法 |
|---|---|---|
| 人物忽大忽小 | 尺度锚定不足 | 增加强锚定，全片统一比例 |
| 视角乱跳 | 提示词含运镜词或首帧未锁 | 写"固定机位/一镜到底/无剪辑" + 负面禁词 |
| 巨物不动 | 环境动缺失 | 每个镜头补一个巨物反应 |
| 穿模 | 相机路径与物体碰撞 | 白模预演检查（见 `06_白模运镜预演.md`） |
| 悬浮无重力 | 缺少重力链 | 跳跃写抛物线下落 + 落地缓冲 |

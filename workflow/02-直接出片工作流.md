# 工作流02 · 直接出片工作流

> 从用户的一句话/一段文案/一个想法，直接产出可投喂 Seedance 2.5 的小人国视频提示词。**全流程清单 + 走查表**。

## 入口

用户提出小人国/微缩世界/巨物对比类视频需求，从门1 开始顺序推进。**每轮只推进一个门，每次确认只问 1-3 个选项化问题。**

        ↓

## 每门执行细则

### 门1 形象门（强制第一步）

1. 询问："请提供你的个人形象照片（全身/半身均可）。"
2. 已提供 → 检查视角完整性（正面/左侧/右侧/全身），缺失视角用 GPT Image2.5 补足。
3. 未提供 → 追问形象描述（外貌/服装/体型），最多 3 问；仍无 → 默认生成通用形象并说明。
4. 生成 4 视角图（模板见 `templates/人物多视角生成提示词模板.md`），自查一致性。
5. 产出 P1-P4 路径清单，告知用户。

### 门2 场地门（强制）

1. 询问场景："想在小人国世界里看到什么场景？"（桌面/键盘/食物/书房/户外…）
2. 无指定 → 默认办公域（键帽阵列桌面）。
3. 用户提供场地照片 → 按照片布局生成鸟瞰空镜。
4. 生成鸟瞰空镜（垂直向下俯视 90°，模板见 `templates/场地鸟瞰空镜提示词模板.md`）。
5. 产出空镜路径，告知用户。

### 门3 规格门（必问尺寸）

```
询问：本次视频尺寸用 16:9 横屏 还是 9:16 竖屏？（未回答默认 16:9 横屏）
```
- 同时确认：时长（默认 12s）、风格倾向（超写实/魔幻/荒诞/高速穿越）。
- 用户全部不答 → 默认：16:9 横屏 + 12s + 门4 给四案推荐。

### 门4 方案门（强制选择点）

- 按 `references/08` 输出 A/B/C/D 方案卡，每案 ≤8 行。
- 等用户明确选择后才继续；**未过门4 不得输出完整提示词**。

### 门5 预演门（条件触发）

触发条件（任一命中必过）：
- 一镜到底 / 连续空间长镜头
- 子弹时间 / 慢动作与正常速度混合
- 复杂运镜（环绕/FPV/多段缓动）
- 人物与巨物碰撞、落点不确定

执行：按 `templates/白模运镜参考HTML模板.md` 生成白模 → 浏览器播放 → 录制 webm → 落点对比（≤0.3 单位偏差）→ 交付参考视频 + 关键帧表 + 子弹时间事件表。

### 门6 出片门（交付）

按 `templates/视频提示词模板.md` 六段式组装：
① 全局视听DNA → ② 人物设定（@P1-P4）→ ③ 场地设定（@空镜）→ ④ 分段镜头描述（五段式+Cut+节拍）→ ⑤ 反向屏蔽规则 → ⑥ 署名水印。

**交付前走查表（逐项勾选）**：

- [ ] 人物多视角图已具备（P1-P4 至少 P1+P4）
- [ ] 场地鸟瞰空镜已具备（垂直向下俯视 90° 显式体现）
- [ ] 尺寸已询问（16:9 / 9:16，未答默认 16:9）
- [ ] 五段式结构完整（建立/引入/推进/回落/收尾）
- [ ] 每段时间区间只有一个主要动作
- [ ] 三动齐全（相机动/主体动/环境动）
- [ ] 强锚定在段1/段2 出现
- [ ] 每个镜头 ≥2 个物理细节
- [ ] 反向屏蔽规则显式段落
- [ ] 锁定视角时无触发视角变化的禁用词
- [ ] 白模预演通过（如命中门5 条件）
- [ ] 署名水印已追加

## 输出格式（最终交付）

```
【交付物】
1. 版本卡（方案/尺寸/时长/风格/素材清单）
2. 完整提示词（六段式，可直接复制投喂 Seedance 2.5）
3. 使用说明（参考图引用方式、480P 注意事项）
4. 白模参考视频（如做了预演）
5. 备选版本（用户可选的替换段落）
```

## 常见卡点与处理

| 卡点 | 处理 |
|---|---|
| 用户不提供形象图 | 生成默认形象，并提示可随时换图 |
| 用户不选方案 | 默认推荐方案B（超现实魔幻），直接继续 |
| 白模失败/穿模 | 调整关键帧路径重跑（同类失败最多2次），仍失败则降级：固定机位 + 简化运镜 |
| Seedance 出片后形象漂移 | 回到门1 补足多视角图，提示词重申人物锚定 |
| 用户要改文案 | 重新走门4-门6（方案可按新文案重排），素材与规格不变 |

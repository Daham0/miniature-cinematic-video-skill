# 03 · 四步主干融合工作流

> 用途：把四步主干、七道门禁、三类知识库模块串成一条可执行的时间线。
> 每个节点都写了**输入 / 动作 / 交接物 / 确认话术**，照做即可，不需要临场设计流程。

## 全局时序

```
S1 多视角素材与空镜 ──┬─ 门1 形象门 ──→ 人物四视角图（3:4 灰底）
                      └─ 门2 场地门 ──→ 场地鸟瞰空镜（俯视90°）
                                        │
S2 四套视觉方案 ──────┬─ 门3 规格门 ──→ 尺寸 / 时长
                      ├─ 门4 方案门 ──→ A/B/C/D 四方案（含 M0–M3 组级策划）
                      └─ 门5 分镜门 ──→ 组块式分镜表（M4–M7 + 电影感八条 + 质检）
                                        │
S3 白模运镜预演 ────── 门6 预演门 ───→ 白模 webm + 落点对比结论 + 四项校验 PASS
                                        │
S4 全自动出片 ──────── 门7 出片门 ───→ 六栏目提示词 → Seedance 2.5 / 480P 成片
```

**顺序不可乱**：素材没定不写分镜，分镜没过质检不写提示词，白模没过校验不投喂。

---

## S1｜多视角素材与空镜

### 节点 1.1 文案接收

- **输入**：口播文案（纯文本）
- **动作**：拆单元，估算口播秒数（字数 ÷ 4.5），判断是否需砍句或提速
- **交接物**：单元清单
- **不在这里**：不写任何镜头

### 节点 1.2 形象门（门1）

- **问**：有没有你的形象图？有就发，没有我按你的描述生成四视角灰底图（3:4，1K）
- **动作**：用户有图 → 检查四视角是否齐全（正面/左侧/右侧/全身），缺的补齐；没有 → GPT Image2.5 生成四张
- **交接物**：@图片P1-P4
- **通过标准**：四视角齐全、同一人、灰底纯色、比例一致

### 节点 1.3 场地门（门2）

- **问**：故事发生在哪？（桌面 / 厨房 / 书桌 / 户外草地 / 数码配件堆 / 零食堆……）你自己有图就发，没有我生成
- **动作**：生成或确认鸟瞰空镜，提示词必须显式写"垂直向下俯视 90° 的鸟瞰空镜"
- **交接物**：@图片X + 场景巨物清单（3–6 个可辨识日常物）+ 尺度基准（人物 ≈ 某巨物的几分之一）
- **通过标准**：俯视 90° 明确、巨物尺寸关系合理、纹理真实可辨（木纹/键帽字符/布纹）

> 场景域扩展与可插拔模块见 `references/05_场景扩展与可插拔模块.md`。

## S2｜四套视觉方案（含策划与分镜）

### 节点 2.1 规格门（门3）

- **问**：16:9 横屏还是 9:16 竖屏？时长默认 12s，要改吗？
- **交接物**：尺寸 + 时长 + 是否口播同步
- **红线**：此门不可跳。未答默认 16:9 / 12s。

### 节点 2.2 组级策划（M0–M3，静默执行）

- **动作**：按 `09_组级策划引擎.md` 跑完 M0 画面化 → M0.5 镜数决策 → M1 功能 → M2 组类型 → M3 结构
- **交接物**：内部用的组头草图（此时不展示给用户，用户看不懂结构术语）
- **注意**：策划结果会决定四套方案的镜头数与节奏差异，不是四套同一份方案换配色。

### 节点 2.3 方案门（门4）

- **动作**：输出 A/B/C/D 四套，每套 ≤8 行，必须给：预估时长 / 组数 / 镜数 / 运镜幅度 / 节奏曲线 / 风险点
- **问**：选哪套？（可回"都要""换一批""按 C 改"）
- **交接物**：选定的方案 + 版本卡
- **红线**：未过此门不得输出完整提示词。

### 节点 2.4 分镜门（门5）

- **动作**：
  1. 按选中方案落组块式分镜表（`templates/分镜表模板_小人国组块式.md`）
  2. 填 M4–M7 参数（景别 L / 方位-高度-焦段 / 转场 / 轴线）
  3. 过电影感八条（`10_镜头约束与电影感.md`）
  4. 跑 `11_质检清单与反模式.md` 四道扫描
- **交接物**：通过质检的分镜表
- **问**：这张表有问题吗？要改哪一组？
- **迭代原则**：**只改被标记的那一项**，改完出 vN 版本并写变更说明，不重跑全链。

## S3｜白模运镜预演

### 节点 3.1 判断是否需要预演

必过：一镜到底 / 子弹时间 / 复杂运镜（环绕、FPV、多段缓动）/ 碰撞落点不确定。

可跳：固定机位为主、单镜内简单缓推、无人物与巨物物理接触。

### 节点 3.2 出白模三件套

- **动作**：按 `references/06_白模运镜预演.md` 出 Three.js HTML（几何体映射 + 相机关键帧 + 人物走位 + MediaRecorder）
- **交接物**：可播放 HTML + 录制的 webm + 落点对比结论

### 节点 3.3 四项校验（PASS 才进 S4）

| 校验 | 判定 |
|---|---|
| 极角单调 | 相机轨迹单向连续，无折返 |
| 主体不出画 | 逐帧 world_to_camera_view，主体 NDC 在画面内 |
| 跨组零穿模 | 相机路径与几何体 ≥0.3 单位安全距 |
| 不穿顶 | 相机高度不超过场景包围盒顶面 |

### 节点 3.4 用户确认

- **问**：运镜节奏这样行吗？哪里要改？
- **迭代**：按大白话→参数翻译表只改一项，出 vN
- **红线**：白模只锁运动，不作为画面参考。

## S4｜全自动出片

### 节点 4.1 写提示词

- **动作**：按白模实测坐标写六栏目（`templates/视频提示词模板.md`）
- **必含**：全局视听 DNA、逐段白描（连续时间区间）、真实感描述（手机质感/手持抖动/运动模糊/浮尘/实用光源反光）、【反向屏蔽规则】、署名水印

### 节点 4.2 出片门（门7）

- **动作**：完整展示提示词 + 参数卡（模型 Seedance 2.5 / 480P / 尺寸 / 时长 / 参考图 @P1-P4 + @X）
- **问**：确认投喂吗？
- **红线**：未确认不得调用接口。

### 节点 4.3 交付与复盘

- **交付物**：白模视频 + 提示词 + 480P 成片 + 修复建议
- **若失败**：查 `references/08_风格方案路由与平台规格.md` 第 5 节失败模式库，按现象对症；同一失败最多修 2 次，仍不行则降级方案（D→B→A）。

## 门禁跳过规则（用户赶时间时）

| 门 | 能否跳 | 条件 |
|---|---|---|
| 门1 形象 | 否 | 没有人物就没有小人国，最低限度要一张正面图 |
| 门2 场地 | 否 | 没有空间锚点无法定机位，最低限度给场景描述生成空镜 |
| 门3 规格 | 否 | 尺寸错了全片白做 |
| 门4 方案 | 可跳 | 用户说"你定"→ 默认方案 A（超写实，风险最低） |
| 门5 分镜 | 可跳 | 用户说"直接出片"→ 内部跑完后只展示镜数与时长的极简摘要 |
| 门6 预演 | 可跳 | 用户说"不用预演，直接出"→ 明确告知穿模与落点风险由用户承担 |
| 门7 出片 | 否 | 必须确认提示词 |

## 常见卡点

| 卡点 | 处理 |
|---|---|
| 用户给的文案太长（>60 字） | 拆成多段视频，或砍到核心一句；不许硬塞进 12s |
| 用户形象图与视频人物不像 | 提示词首句强制"人物外貌服装与@图片P1完全一致"，补 P2-P4 |
| 用户要"高级感" | 转成具体手段：浅景深+窗光+微距+浮尘，禁用"高级感"入词 |
| 用户中途换场景 | 回门2 重出空镜，分镜表 G1 之后全部重排 |
| 480P 细节糊 | 降细节密度、增大主体占比、简化背景（不是加分辨率） |

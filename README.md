# 小人国电影感出片Skill

**一段口播文案进来，一条 480P 小人国成片出去。**

人物以微缩尺度出现在巨型日常物体构成的奇观世界里——键盘是街区、杯子是高楼、灰尘是沙暴。这个 Skill 把整条链路串起来：文案 → 多视角人物图与鸟瞰空镜 → 四套风格方案 → 组块式分镜表 → 3D 白模运镜预演 → 组块式分镜 → 即梦 Seedance 2.5 出片。

由 [@拍广告的Daham](https://github.com/Daham0) 制作，抖音小红书同号。

## 四步怎么用

### 第一步 · 多视角素材与空镜

把口播文案丢给它。它会先备底图：

- 没有人物图 → 自动生成 **3:4 竖版灰底四视角人物参考**（半身正面 / 左侧 / 右侧 / 全身），作为全片人物身份锚（@图片P1-P4）。
- 接着问你故事发生在哪 → 你给图或给描述，它出一张 **垂直向下俯视 90° 的鸟瞰空镜**，锁定微缩世界的空间关系与巨物尺度（@图片X）。

### 第二步 · 文案生成四套视觉方案

把文案做视觉化拆解，给四套风格，运镜幅度与节奏各不相同，并算好预估时长与镜头数量：

| 方案 | 风格 | 冲击力 | 难度 |
|---|---|---|---|
| A | 超写实 | ★★ | ★ |
| B | 超现实魔幻 | ★★★ | ★★ |
| C | 荒诞无厘头 | ★★★ | ★★ |
| D | 高速穿越（FPV / 子弹时间） | ★★★★★ | ★★★★ |

你只选一个最对味的。选完它会落一张 **组块式分镜表**：每组一个叙事功能（起因 / 经过 / 结果），组内强制景别大跳、机位差 45° 以上、必出一处微距爆点，并过四道质检——叙事、镜头、尺度、出片。

### 第三步 · 白模运镜预演防翻车

怕直接生成浪费积分？它先出图片参考，再转成 **3D 白模预演动画**（Three.js，浏览器打开即播）。你能提前看到整个镜头的空间关系、运镜路径和节奏，确认没问题再往下走。四项校验不过不放行：运镜单向不折返、主体不出画、零穿模、不穿顶。

### 第四步 · 全自动调用生成成片

提示词它会自己加料——手机质感、手持轻微抖动、运动模糊、浮尘、实用光源反光，让画面更像实拍。确认完提示词直接连即梦接口调 **Seedance 2.5**：把空镜、人物图、提示词全喂进去，自动出 **480P** 成片。画幅尺寸、各项参数都固定好，你只管验收。

## 为什么是这么排的

小人国视频最容易翻车的不是画面不好看，而是**镜头之间没有因果**——一堆漂亮微距空镜堆在一起，人物忽大忽小，观众不知道在看什么故事。

所以这个 Skill 的顺序是硬的：

```
先定组 → 再定镜头 → 再过质检 → 才写提示词
素材没定不写分镜，分镜没过质检不写提示词，白模没过校验不投喂
```

反过来（先想一个炫酷机位再硬塞进叙事）产出的镜头，基本过不了第四道质检。

## 七道门禁

| 门 | 名称 | 通过标准 | 可跳 |
|---|---|---|---|
| 门1 | 形象门 | 四视角人物图齐全、同一人、灰底 3:4 | 否 |
| 门2 | 场地门 | 垂直俯视 90° 鸟瞰空镜 + 巨物清单 | 否 |
| 门3 | 规格门 | 尺寸（16:9 / 9:16）+ 时长已定 | 否 |
| 门4 | 方案门 | A/B/C/D 四选一并出方案卡 | 可（默认 A） |
| 门5 | 分镜门 | 组块式分镜表过四道质检 | 可（内部跑完给摘要） |
| 门6 | 预演门 | 白模四项校验 PASS | 可（风险自负） |
| 门7 | 出片门 | 提示词与参数已确认 | 否 |

## 需要什么

- 一个即梦账号（Seedance 2.5 视频 + GPT Image2.5 图片）
- 能跑浏览器的电脑（白模预演是 Three.js 单文件 HTML，无需装 Blender）
- 把本仓库整个目录放进你所用 Agent 的 skills 目录即可，`SKILL.md` 是入口
